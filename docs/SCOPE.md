# Initial scope

0.1.0 covers goal.md M0–M4: property generation, default Unicode line/word/sentence
boundaries, greedy wrapping, four alignments, exact UTF-8 source ranges and four
examples. Unicode normalization, bidi reordering, shaping, rendering, NLP,
optimal wrapping and hyphenation are outside this release. See LIMITATIONS.md
for exact width and whitespace contracts and INITIAL_ACCEPTANCE.md for evidence.
