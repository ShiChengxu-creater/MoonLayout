# Release scope

0.2.0 is the final-acceptance release selected by the user. It retains M0–M4 and implements M5–M8: simplified optimal wrapping, pluggable English Liang hyphenation, optional ecosystem BiDi/NFC/NFKC integration, eight examples, measured benchmarks, differential tests and API documentation. Core algorithms remain pure MoonBit and deterministic.

Out of scope: shaping, fonts, rasterization, full TeX, Markdown parsing, NLP/dictionary segmentation, all-language hyphenation and pagination. See LIMITATIONS.md. Generated Unicode/English data and conformance fixtures are counted separately from handwritten code; planned line counts are estimates, not a reason to duplicate code.
